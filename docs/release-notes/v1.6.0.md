修复大文件打开与只读状态的问题，并把安卓界面文案收进资源文件。

## 修复

- **桌面端不再整份读入超大文件。** 打开超过 16 MiB 的文件时只读取开头 16 MiB 用于只读展示，状态栏说明"仅显示开头部分"；此前整份读入，几百 MB 的文件会把内存撑爆。截断只发生在只读视图，不会写回原文件。
- **只读文档禁用保存。** 只读打开后「保存」与 Ctrl+S 一并置灰，「另存为」仍可用；另存为选回原文件会被拒绝，避免把只有开头部分的内容覆盖掉整个文件。文件头徽标长期显示"只读 · 仅开头"，状态栏另有一行说明。
- **安卓超限提示与行为一致。** 打开超过 16 MiB 的文件时提示"未打开；当前内容保留"，不再显示"已按只读方式打开"。
- **安卓空查找词不再弹提示。** 查找词为空时「下一处 / 替换」置灰，与桌面端一致；输入法直接提交仍会给出提示。

## 改进

- 安卓的菜单、确认对话框、Toast 与状态提示改从 `strings.xml` 读取，同一句文案只维护一份。

## 安装

- **Android 8.0 及以上**：下载 `TXTDesign-android.apk`，允许当前来源安装应用。
- **Windows x64**：下载 `TXTDesign-1.6.0.exe`，自带 Temurin Java 21 运行时，按当前用户安装。
- **已有 Java 8+**：下载 `txteditor-windows.jar`，运行 `java -jar txteditor-windows.jar`。
- `SHA256SUMS.txt` 提供以上文件的 SHA-256 校验值。

安卓包沿用演示用调试证书，自动构建之间不保证同签名，覆盖安装前请先把文档保存到应用外；Windows 安装器未做商业代码签名。
