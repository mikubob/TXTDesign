## 编辑与预览

- Windows 和 Android 的查找新增「上一处」和匹配总数，并支持跳转到指定行。
- 修复 Windows 保存失败后无法从弹窗另存的问题。Android 保存原文件前核对内容，发现改动或无法确认原版本时提供覆盖、另存为和取消。
- 修复 Android 大草稿写入后无法读回的问题。Android 文件保存和重新打开统一使用 16 MiB 上限，超限保留编辑内容。
- Markdown 未闭合链接标记减少重复扫描，超出块节点上限时显示纯文本。两端使用相同的 UTF-8 降级阈值，并统一有序列表及任务列表的标记。

## 下载

- **Windows 10/11 x64** 下载 `TXTDesign-1.7.0-Setup-win-x64.exe`。新版采用 NSIS 简体中文安装向导，随包提供 Temurin Java 21，可选择目录，按当前用户安装。旧版 Windows 安装器的用户请先关闭应用，通过系统卸载旧版，再安装新版。应用设置和草稿继续使用现有用户数据目录。
- **Android 8.0+** 下载 `TXTDesign-android.apk`。自动构建使用演示用调试签名，签名不同的旧版无法直接覆盖。处理签名冲突前，请先把未保存文档保存到应用外。
- 已安装桌面 Java 8+ 可直接使用 `txteditor-windows.jar`。`SHA256SUMS.txt` 提供附件校验值。
