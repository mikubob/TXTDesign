## 编辑与导航

- Windows 和 Android 新增全部替换，显示替换数量，支持留空删除和一次撤销。
- 最近文件恢复上次光标与源码视口，兼容旧位置记录。
- Markdown 新增标题大纲、预览定位源码和分屏按块滚动同步。
- 新增缩进、反缩进、复制当前行，以及 Markdown 待办和代码围栏快捷插入。
- 编辑区新增行号开关和括号匹配。Java、C、C++、JSON 支持折叠多行括号块。

## 下载

- **Windows 10/11 x64** 下载 `TXTDesign-1.8.0-Setup-win-x64.exe`，内含 Java 21 运行时。已有桌面 Java 8+ 也可使用 `txteditor-windows.jar`。
- **Android 8.0+** 下载 `TXTDesign-android.apk`。自动构建使用演示用调试签名。遇到签名冲突时，请先将文档保存到应用外再处理旧版。
- 附件的 SHA-256 校验值见 `SHA256SUMS.txt`。
