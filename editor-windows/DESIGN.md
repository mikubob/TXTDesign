# 设计与课程目标说明

本实现按照根目录策划书和开发协作约定建立共享核心、Windows 界面两层。课程目标 1 对应自行实现数据结构与算法并验证正确性；课程目标 2 对应需求、模块边界、输入适配、文件保护、协作接口和可复现的构建/测试记录。根目录需求文档与安卓目录未由本任务修改。

`editor-core` 中 `GapBuffer` 自行实现 char 数组的间隙移动、扩容和逻辑索引。`Kmp` 自行生成前缀表并遍历逻辑字符，没有导出字符串后使用 indexOf 冒充算法。`EditorModel` 统一替换入口；私有 Edit 保存起点、删除/插入文本、操作前选区与操作后光标，以两个标准库 ArrayDeque 管理撤销/重做。超出 100 条删除最旧记录，撤销后新编辑清空重做。保存基准保留文本快照，解决撤销回保存点的脏状态判断。

`TextCodec` 仅编解码字节并统一换行；核心没有 Path、文件 URI、Swing、Android 依赖。Windows 的 `SafeFiles` 处理本地路径与临时替换，安卓复用算法而使用自己的 URI 文件适配。文件加载先完整解码验证，再由 UI 线程一次加载；保存把文本快照交给工作线程，成功后才标为已存。

Swing `EditorBinding` 是唯一编辑适配，`EditorWindow` 负责菜单、提示、查找与异步文件操作。标准 Swing 输入控件保留剪贴板、选区显示和输入法组合行为，共享模型保留真正的文本算法及历史。组合输入事件的人工验收仍有待补齐，合成组合事件测试不等于输入法真机测试。

2026-10-28 的 Windows 界面升级使用固定版本 FlatLaf 3.7.2。`EditorTheme` 集中定义明暗色板和 Swing UI 默认值；`EditorIcon` 仅绘制工具图标，正文仍为 JTextArea。工具栏和菜单复用同一 Action，异步文件操作期间同步禁用。查找替换区按需展开、Escape 关闭回正文，宽度 ≥ 960 逻辑像素时停靠右侧（上限 320），否则回到顶部条；矮窗口收起抬头与文件信息行。正文缩放只改字体，不进入共享历史。中文正文字体通过 Swing StyleContext 获得字体回退，兼顾微软雅黑和表情显示。构建仅在本模块编译共享源码副本的字节码，不写共享核心目录。

2.0 升级在核心侧加了编辑事务、文案键和会话快照结构：`EditorModel.beginTransaction/endTransaction` 把相邻、同段落、间隔小于 500ms 的替换合并成一条历史，撤销整条还原并回到事务开始前的选区；`TextKeys` 只提供默认中文文案，呈现方式留在各端；`SessionSnapshot` 是纯结构体，序列化在平台层。Windows 侧由 `EditorStore` 把会话草稿与视图偏好写入 `%LOCALAPPDATA%\TXTDesign\session\`，草稿复用 `SafeFiles` 的临时文件加原子移动，编辑后 700ms 防抖，启动时比较 `lastExit` 决定是否恢复；偏好文件保存三态主题、窗口几何、缩放与最近 5 条文件，窗口还原点落在已拔掉的显示器时回落主屏居中。文件通路补了拖放、最近文件、保存前 mtime/大小比对与 16 MiB 只读保护。

| 操作 | 核心时间 | 额外空间 |
| --- | --- | --- |
| 逻辑字符读取 | O(1) | O(1) |
| 替换 k 个代码单元 | O(d+k)，扩容另加 O(N) | 删除/插入历史 O(k)；扩容 O(N) |
| KMP 单轮 | O(N+M) | O(M) |
| 撤销重做 | 对应替换成本，栈转移摊还 O(1) | 已保留历史 O(H) |
| 导出、码点统计、行数与保存基准比较 | O(N) | 导出 O(N)，统计/比较 O(1) |

d 是间隙移动距离，N 是文档长度，M 是模式长度，H 是保留命令中的文本总量。界面自身仍有文本镜像、统计和重绘成本，不能把完整按键响应等同于间隙附近插入的成本。历史条数有限但每条可很大，所以 100 条上限不代表固定内存上限。当前定位为 10 万 UTF-16 单元以内的小型文本；不增加尚未要求的分块文件和复杂缓存。

正确性通过 StringBuilder 随机对照、String.indexOf 对照（仅在测试中）、代理项与历史边界测试、Swing 适配测试以及模拟非原子保存失败验证。性能实验将核心与界面/文件操作分别测量，先预热再重复 30 次记录中位数与最大值。报告不把本机结果推断为所有设备保证。

演示建议：打开 sample.txt → 中文与表情编辑 → 剪切/粘贴 → 查找替换 → 撤销/重做 → 保存重开 → 修改后取消新建 → 查看 CoreTest 和基准 CSV。答辩可解释 gapStart/gapEnd 不变量、KMP 前缀回退、历史逆操作、UTF-16 边界和临时文件替换流程。
